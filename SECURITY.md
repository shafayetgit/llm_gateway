# Security Policy

## Reporting Security Issues

If you discover a security vulnerability within **LLM API Gateway**, please do **NOT** open a public issue.

Instead, please report the vulnerability privately by emailing the maintainers or using GitHub's private vulnerability reporting feature.

### Response & Handling
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an estimated timeline for remediation and keep you informed of progress.
- Public disclosure will take place only after a patch has been released.
